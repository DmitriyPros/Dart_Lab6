**В данной лабораторной работе изучаются основы работы с классами. Подробно изучаются методы классов, наследования, абстрактные классы, полиморфизм и переопределение методов.**

**Как запустить:**
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab6_rpg`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`
***
**Что изучили:**
1. Основные правила работы с классами 
2. Абстрактные классы, полиморфизм
3. Методы классов, такие как `super`
4. Переопределение функций у разных наследников классов
***
**Ответы на вопросы:**
1. Абстрактный класс — это шаблон, который нельзя инстанцировать. `Character()` нельзя написать напрямую, потому что у него есть методы без реализации.

2. `super` инициализирует поля родителя (`name`, `health`). Без него — появится ошибка компиляции (или поля останутся `null`).

3. `attack()` в родителе абстрактный (нет тела, пишем с нуля). `takeDamage()` имеет реализацию в родителе, а в `Warrior` переопределяется, чтобы изменить стандартное поведение.

4. Эта концепция называется полиморфизм. Во Flutter мы её уже видели так: тип `Widget` (под ним скрываются `Text`, `Container` и т.д.).

5. Нижнее подчеркивание _ — это приватность. Поле `_random` доступно только внутри файла `character.dart`.
